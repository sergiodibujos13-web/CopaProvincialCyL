# Copa Provincial

1. Sube todo el contenido de esta carpeta a un repositorio de GitHub (incluida la carpeta .github).
2. En la pestaña Actions se ejecuta "Build APK". Al terminar, descarga el artefacto copa-provincial-apk.
3. Los IDs de anuncios son de PRUEBA (AndroidManifest.xml y Ads.kt). Cambialos por los tuyos de AdMob antes de publicar.
4. Equipos inventados en Game.kt (teamNames). Los nombres tambien se editan dentro de la app.
